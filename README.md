# TempMail TUI

Консольный клиент временной почты для терминала: цветной интерфейс, мышь, список недавних ящиков и два независимых провайдера — **[mail.tm](https://mail.tm)** (ящик с паролем) и **[maildrop.cc](https://maildrop.cc)** (без регистрации).

Внешних зависимостей почти нет: только `requests`. Интерфейс нарисован вручную через ANSI и `ctypes`, никаких `curses`/`textual`.

```
┌ ВРЕМЕННАЯ ПОЧТА · mail.tm ─────────────────────────────── новых 1 ┐
│ ящик: ab12cd34ef@mail.tm                    c — копировать адрес  │
├───────────────────────────────────────────────────────────────────┤
│ #   от                    тема                      получено      │
│ 1   GitHub <noreply@…>    [GitHub] Please verify…   12:04         │
├───────────────────────────────────────────────────────────────────┤
│ ↑↓ Enter · d письмо · D почту · n новая · , настройки · ? справка │
└───────────────────────────────────────────────────────────────────┘
```

## Возможности

- два провайдера на выбор, переключение прямо в интерфейсе;
- меню входа со списком недавних ящиков — можно вернуться в старый ящик;
- таблица входящих с рамками, цветом, прокруткой и счётчиком новых писем;
- сортировка по дате / отправителю / теме, по возрастанию и убыванию;
- автоматический опрос сервера с настраиваемым интервалом;
- TTL: авто-удаление писем старше N минут;
- авто-удаление письма через N секунд после прочтения;
- ограничение на количество хранимых писем;
- просмотр письма с прокруткой; HTML конвертируется в читаемый текст;
- клик по коду/токену в письме — копирование в буфер обмена;
- управление мышью: клики по письмам, пунктам меню, колесо прокрутки;
- настройки сохраняются в `tempmail_config.json` рядом с программой.

## Требования

- Python 3.9+ (Windows 10/11 — рекомендуется: есть мышь и стрелки);
- на Linux/macOS работает базовый режим без мыши (fallback на stdin);
- интернет: обращения идут к `api.mail.tm` и `api.maildrop.cc`.

## Быстрый старт

```bash
git clone https://github.com/<ваш-логин>/tempmail-tui.git
cd tempmail-tui
pip install -r requirements.txt
python tempmail.py
```

При первом запуске выберите провайдера, нажмите `Enter` — ящик создастся автоматически.
Адрес копируется клавишей `c`.

## Сборка одного .exe (Windows)

```powershell
pip install requests pyinstaller
pyinstaller --onefile --console --name TempMail tempmail.py
```

Готовый файл: `dist\TempMail.exe`. Рядом с ним появится `tempmail_config.json`.

В репозитории есть готовый `TempMail.spec`, поэтому можно и так:

```powershell
pyinstaller TempMail.spec
```

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓`, колесо | выбрать письмо / пункт меню |
| `Enter` / клик | открыть письмо, подтвердить выбор |
| `d` / `Del` | удалить выбранное письмо |
| `D` | удалить текущий ящик целиком |
| `c` | скопировать адрес ящика |
| клик по коду в письме | скопировать фрагмент |
| `Esc` / `m` | вернуться в меню выбора ящика |
| `,` | настройки |
| `s` / `o` | сменить поле / порядок сортировки |
| `t` / `p` / `i` | быстро изменить TTL / удаление после чтения / интервал опроса |
| `n` | создать новый ящик (с выбором сервиса) |
| `r` | обновить сейчас |
| `?` | справка по клавишам |
| `q` | выход |

## Провайдеры

| Провайдер | Адрес | Пароль | Удаление | Время жизни |
| --- | --- | --- | --- | --- |
| `mail.tm` | генерируется на домене сервиса | да, генерируется | писем и ящика | пока ящик не удалён |
| `maildrop.cc` | `<имя>@maildrop.cc`, имя можно задать | не нужен | недоступно (скрывается локально) | ~24 часа |

maildrop.cc работает через GraphQL API сервиса; если сервис меняет схему, запросы могут перестать отвечать — в этом случае переключитесь на mail.tm.

## Конфигурация

Файл `tempmail_config.json` создаётся рядом со скриптом или `.exe`:

```json
{
  "provider": "mailtm",
  "poll_interval": 5,
  "message_ttl_minutes": 30,
  "delete_after_read_seconds": 0,
  "keep_last": 100,
  "sort_by": "date",
  "sort_order": "desc",
  "color": true,
  "mailbox": { "provider": "mailtm", "address": "…", "password": "…" },
  "recent": []
}
```

- `provider` — провайдер для новых ящиков: `mailtm` или `maildrop`;
- `poll_interval` — период опроса, сек;
- `message_ttl_minutes` — удалять письма старше N минут (`0` — выключено);
- `delete_after_read_seconds` — удалять через N секунд после прочтения (`0` — выключено);
- `keep_last` — хранить не более N писем (`0` — без лимита);
- `sort_by` — `date` / `sender` / `subject`;
- `sort_order` — `desc` / `asc`;
- `color` — цветной вывод.

Всё то же самое меняется из интерфейса по клавише `,`. Файл содержит адреса и пароли ваших временных ящиков, поэтому он в `.gitignore` и не попадает в репозиторий.

## Ограничения

- сервисы временной почты публичные: не используйте их для регистраций, где нужен постоянный доступ или конфиденциальные данные;
- письма в maildrop.cc нельзя удалить на сервере, клиент лишь скрывает их у себя;
- интерфейс рассчитан на терминал высотой от ~20 строк; при уменьшении окна таблица ужимается.
